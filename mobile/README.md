# ECHO mobile 0.23

Мобильная сборка использует действующий `../index.html` 0.22 и SDK Supabase 2.117.2 из `vendor/`. Исходный сайт не меняется. Отдельная копия HTML для мобильного приложения генерируется во время сборки с обновлённым CSP и нативными обработчиками.

- Android и iOS: локально встроенный интерфейс, добровольное ежедневное напоминание, нативный экспорт данных, обработка возврата/Android Back.
- Напоминание не содержит личных текстов; выход и смена аккаунта отменяют его. На некоторых телефонах время доставки может отличаться. Push о сообщениях ещё не подключены.
- Вход по почте/паролю. Подтверждение и восстановление идут через https://echoacross.github.io/; автоматический возврат из письма в приложение ещё не подключён.
- Предварительный Bundle ID: `io.echoacross.app`. Иконки и запуск пока из шаблона; оформление нужно завершить перед публикацией.

## Проверка и сборка
```sh
cd mobile
npm ci
npm run prepare:platforms
npm test
```
Скрипт создаёт Android/iOS из фиксированного Capacitor 8.5.2, добавляет настройки приватности и синхронизирует плагины. Android требует JDK 21 и SDK 36. iOS требует macOS и Xcode 26+. Повторный запуск безопасен для уже созданных платформ.

Workflow **ECHO mobile check** запускает две облачные сборки. Android выдаёт debug APK; iOS выдаёт неподписанную сборку для симулятора — она не устанавливается на iPhone. Для TestFlight нужны подпись и Apple Developer, настраиваемые отдельно. Платные сервисы и ключи отправки push не подключены.

Проверки кода не заменяют испытания на устройствах, аудит безопасности или одобрение магазинами. Перед публикацией требуется проверить реальный вход, сохранение, экспорт, уведомления, две учётные записи, резервные копии и модерацию. Формат анонимного общения отдельно проверяется по Apple Review Guidelines 1.2.
